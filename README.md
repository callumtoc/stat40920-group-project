# STAT40920 Group Project: Equity Portfolio Advice for a DB Pension Scheme

Group project for **STAT40920 Actuarial and Financial Maths I** (UCD), worth 20% of the module grade.

## The project

Our group has been hired to advise the trustees of a **US defined benefit (DB) pension scheme** on the **equity part** of their investment portfolio. We do not model the scheme's liabilities or its other investments, but we do consider how a DB scheme's objectives affect the trustees' attitude to investment risk.

We must recommend **three portfolios**:

| Portfolio | Purpose |
|---|---|
| Low risk | For trustees who put stability first |
| Medium risk | A balance between risk and return |
| High risk | For trustees seeking higher expected return |

Each portfolio:

- is a percentage allocation across **our ten permitted industry sectors** only (no cash, other asset classes or other sectors)
- comes with a recommended **rebalancing frequency** (monthly, quarterly or annually)
- is compared over a **five-year investment horizon**, covering both potential rewards and the risk of adverse outcomes

## The report

- Written for trustees who are **financially literate but not specialists** in portfolio mathematics.
- Explains our process, assumptions, results and the limitations of our modelling.
- May cover risk and return measures, diversification, historical (backtest) performance and the outlook for our sectors.
- **8–10 A4 pages** recommended. Pages after 11, including the cover, are not marked.

| File | Description |
|---|---|
| [`data/raw/49_Industry_Portfolios.csv`](data/raw/49_Industry_Portfolios.csv) | 49 Industry Portfolios: monthly and annual returns (value- and equal-weighted), number of firms, firm size and BE/ME |

## How to run

```
pip install -r requirements.txt
python code/run_all.py
```

`python code/run_all.py` produces all outputs, including the forecast. It runs the analysis scripts in dependency order (summary statistics, correlation/covariance, portfolio allocations, efficient frontier, chart, forecast, Excel export). Any failure stops the run, so outputs in `output/` can't go stale.

The last step writes `output/results.xlsx`: every output table, already formatted (%, $, headers), plus the charts, one tab each. Copy tabs from it into the group workbook instead of pasting CSVs by hand. Close `results.xlsx` in Excel before re-running, otherwise the file can't be overwritten.

### Settings

All settings live in [`code/portfolio_utils.py`](code/portfolio_utils.py) and nowhere else:

| Setting | Current value | Meaning |
|---|---|---|
| `RISK_FREE_RATE` | `4.346` (calculated) | Annual risk-free rate `e` in %: the average one-month T-bill return (`RF` in the Fama/French factors file) over the estimation window, × 12. Used for Sharpe ratios and the High Risk (max-Sharpe) portfolio. Calculated, not set by hand. |
| `ESTIMATION_START`, `ESTIMATION_END` | `"1970-01"`, `"2025-12"` | Months of data used for all estimates: full calendar years in which all ten sectors have returns (Healthcare starts July 1969). |
| `WEIGHT_LIMITS` | A `(0, 0.30)`, B `(-0.10, 0.30)`, C `(-0.20, 0.40)` | Per-sector weight limits for each portfolio. A is long-only (Chapter 6, §6.5); B allows limited short selling; C allows short selling within limits (§6.4, bounded). Each portfolio and its efficient frontier are calculated under its own limits. |
| `SEED` | `40920` | Random seed for the Monte Carlo and bootstrap draws, so results are repeatable. |
| `N_SIMULATIONS` | `10_000` | Number of simulated five-year paths (K). |
| `HORIZON_MONTHS` | `60` | Forecast horizon in months (T). |
| `INITIAL_FUND` | `1_000_000` | Initial investment in $ (F0). |
| `REBALANCE_MONTHS` | `{"A": 12, "B": 3, "C": 3}` | Months between resets to target weights in each portfolio's forecast. Chosen with `rebalancing_decision.py`: switch from annual only if a more frequent option gives more than 1% higher backtest value with no worse drawdown. |
| `REBALANCE_FREQUENCIES` | `{"Monthly": 1, "Quarterly": 3, "Annual": 12, "Never": None}` | The frequencies compared in the backtest and the in-simulation comparison. |
| `BACKTEST_START`, `BACKTEST_END` | `"2021-01"`, `"2025-12"` | Historical window for the rebalancing backtest (60 months). |
| `PORTFOLIO_KEYS` | `{"A": "low_risk", "B": "medium_risk", "C": "high_risk"}` | Maps portfolio letters to the rows of `output/portfolio_allocations.csv`. |
| `PORTFOLIO_LABELS` | `{"A": "Portfolio A (Low Risk)", ...}` | Display names used in tables, charts and output CSVs. |
